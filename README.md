# 🚗 Car Service Reminder System

## 📌 Project Overview

The Car Service Reminder System is a web-based application developed to simplify vehicle service booking and help vehicle owners keep track of important service schedules and document expiry dates. It provides a convenient platform for managing service appointments, vehicle pickup requests, and reminders for essential vehicle maintenance and legal requirements.

## 🎯 Problem Statement

Vehicle owners often forget scheduled maintenance, upcoming service dates, and important document expiry dates, which can lead to delayed servicing and compliance issues. Manual appointment management can also make it difficult to coordinate service schedules and vehicle pickups. This system aims to address these problems through centralized service management and automated reminders.

## 🎯 Objectives

* Simplify vehicle service booking and appointment management.
* Help users track vehicle maintenance schedules.
* Provide reminders for important vehicle documents and expiry dates.
* Manage service availability and vehicle pickup scheduling.
* Reduce missed service appointments through timely notifications.

## ✨ Key Features

### 👤 User Features

* Book vehicle servicing online.
* View and manage service bookings.
* Request vehicle pickup when available.
* Receive reminders for upcoming services.
* Track important document expiry dates.

### 🛠️ Admin Features

* Manage available service slots.
* Control service availability and pickup options.
* Monitor customer bookings and service requests.
* Manage service scheduling.

### 🔔 Reminder Management

* Service-based reminders for scheduled vehicle maintenance.
* Legal reminders for PUC certificates, insurance, and driving licence expiry.
* Email notifications to help users prepare for upcoming service dates and document renewals.

## 🔄 System Workflow

1. The user accesses the website and submits a vehicle service booking.
2. The user selects an available service date and, if required, a vehicle pickup option.
3. The system records the booking details.
4. The administrator manages available service slots and monitors bookings.
5. The system helps users keep track of scheduled maintenance and important document expiry dates through reminders.
